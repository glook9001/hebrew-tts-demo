# ReNikud model

`renikud.onnx` is the unmodified `model.onnx` from https://huggingface.co/renikud/renikud
(SHA-256 8b881a3a8f00283d86c6d1feea44d37e09c1ea6609a4de7d820d937e7f3dbbca).
`renikud.json` is the vocabulary metadata copied from that file's ONNX metadata.
