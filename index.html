05 / ABOUT

  • Model: PiVo-TPU-7M Hebrew v3: 6,511,317 acoustic + 816,597 FARGAN vocoder parameters (7,327,914 total). ONNX files on device: 29.5 MB (float32).
  • Training: about 11.5 h of Hebrew speech (SASPEECH), 20-dim FARGAN features at 16 kHz, trained on a Kaggle TPU v5e-8.
  • Text: example sentences were phonemized with Phonikud (CC BY 4.0). Typed text uses Horse Nikud for vowel marks plus a JavaScript port of Phonikud's rules (CC BY 4.0), so stress on typed text is approximate.
  • Limits: an experimental research model: some speech sounds muffled or buzzy, pitch is fairly flat, and commas get short pauses. Numbers should be written as words.

Based on PiVo-1.4M by Empero Research (Apache-2.0; FARGAN vocoder under the Xiph/Opus BSD license, see NOTICE, THIRD_PARTY.md). Page design inspired by ldenoue/PiVo-1.4M-web. Runs on ONNX Runtime Web. Reference recordings from SASPEECH. Hebrew vowel marks: Powered by Horse Models (https://2008-horse.com/licensing/), non-commercial use, license.
